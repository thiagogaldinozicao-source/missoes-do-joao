# 🎮 Missões do João

App de missões do João: faz missão, ganha ponto, troca por prêmio ou guarda pra bike.

- **App:** https://thiagogaldinozicao-source.github.io/missoes-do-joao/
- **Dados:** planilha "Missões do João" no Google Drive (abas Historico, Missoes e Premios)
- **Ponte com a planilha:** Google Apps Script da própria planilha (`Codigo.gs`)

Pra mudar missões ou prêmios, edita as abas **Missoes** e **Premios** da planilha. O app atualiza sozinho.
